# Tic Tac Toe

A beautifully styled Tic Tac Toe game with multiple themes, animations, and score tracking.

## Features

### 🎨 Multiple Themes
- **Dark** - Classic dark theme with vibrant colors
- **Neon** - Cyberpunk-inspired glowing neon colors
- **Retro** - 8-bit pixel art style retro theme
- **Minimalist** - Clean black and white design
- **Light** - Clean light theme for daytime play

### ✨ Animations
- Smooth X/O placement animations
- Winning line highlight with pulsing effect
- Celebration confetti on victory
- Button press and hover effects
- Message slide-in animations

### 🎮 Game Features
- Two-player local multiplayer
- Win detection (8 winning conditions)
- Draw detection
- Score tracking (X wins, O wins, Draws)
- Score persistence using localStorage
- Theme preference saved across sessions
- Reset game button
- Reset scores button

### 📱 Responsive Design
- Mobile-friendly layout
- Touch-optimized controls
- Adaptive sizing for different screen sizes

## How to Play

1. Open `pri.html` in your web browser
2. Click on any cell to place your mark (X goes first)
3. Players alternate turns
4. Get three marks in a row (horizontal, vertical, or diagonal) to win
5. Use the theme selector to switch between visual themes
6. Track your wins and draws in the score board
7. Reset the game to play again without losing scores
8. Reset scores to start fresh

## Files

- `pri.html` - Main HTML structure
- `pri.css` - Styling with theme system and animations
- `pri.js` - Game logic and interactivity

## Browser Compatibility

Works in all modern browsers that support:
- CSS Custom Properties (CSS Variables)
- CSS Animations
- localStorage API
